## Time Limiter System

This is a module for [AzerothCore](http://www.azerothcore.org) that adds a curfew for players that starts and ends at specific times. Created for a friend and their family that has self control issues.

Current features:

-**Very basic schedule that applies to every day, no customization provided at the moment.

## Requirements

Time Limiter System module currently requires:

AzerothCore v1.0.1+

## How to install

###1) Simply place the module under the `modules` folder of your AzerothCore source folder.

###3) Re-run cmake and launch a clean build of AzerothCore

**That's it.**

### (Optional) Edit module configuration

If you need to change the module configuration, go to your server configuration folder (e.g. **etc**), copy `time_limiter_system.conf.dist` to `time_limiter_system.conf` and edit it as you prefer.
